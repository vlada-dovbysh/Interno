# Interno

A modern and responsive interior design website created as a training project. The project focuses on clean UI, responsive layouts, and structured content presentation.

## 🛠 Technologies

* HTML5
* CSS3
* Responsive Web Design
* Git & GitHub

## ✨ Features

* Responsive and adaptive layout
* Modern interior design interface
* Semantic HTML structure
* Navigation and interactive elements
* Optimized layout for different screen sizes
* Clean and reusable CSS

* [Live Demo](https://vlada-dovbysh.github.io/Interno/)

## 📌 Project

This project was developed to practice frontend development, responsive design, semantic HTML, CSS styling, and working with GitHub Pages for deployment.
